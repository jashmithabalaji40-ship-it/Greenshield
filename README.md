# GreenShield — AI Phone Security

GreenShield is a responsive front-end prototype for a hackathon project focused on helping users learn about phone security and recognize suspicious links.

## Features

- Welcome screen with name and preferred-language selection
- Language options for English, Telugu, Hindi, Tamil, and Kannada (additional options are shown in the interface; translation coverage varies)
- Responsive layout for mobile phones and desktop/laptop screens
- Demo chat assistant with general phone-safety guidance
- GreenShield shield branding and green cybersecurity theme

## Run the prototype

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter a name, choose a language and device, and select **Next** to try the demo assistant.

## Important limitations

- This is a front-end demonstration. The chat assistant uses predefined example responses and is **not connected to a live AI model**.
- It does not perform real device scans, detect malware, or send reports to a security service.
- Language translations are a prototype and may not cover every piece of text in every language.
- Do not enter real passwords, verification codes, or other sensitive information.
